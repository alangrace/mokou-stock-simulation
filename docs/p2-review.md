## 4. 是否切 P3 的建议

**建议切，但按下面顺序，不要跳步。**

### 先做（必须，1–2 小时）

1. **入场拦截对齐**：`proposal.py` 调用 `planner.entry_blockers` + 拦截 `min_score`；
2. **dry-run 与规则引擎同源**：两条路径共用同一套 gate 函数，避免再次分叉；
3. 补测试：RSI 超限、未站上 MA20、评分不足、振幅超限都要被拒。

### 再开写（P3）

1. **P1b**：`agent plan-update` 真正写 `position`（带 20h 冷却、2% 台阶、只上移）；
2. **P3 下单**：新增 `agent trade --execute`，但只允许通过同一套 gate；
3. **开关**：`SAYU_AGENT_TRADING=0/1`，默认 0；
4. **上限**：
   - 单笔 ≤ 5% 权益（沿用防御档单票上限）；
   - 单日 ≤ 2 笔 Agent 成交；
   - 单日 Agent 成交金额 ≤ 10% 权益；
   - 单日亏损 ≥ 2% 时自动停用 Agent 成交；
5. **保留规则 tick**：`tick` 继续跑，作为兜底和对照。

### 主要风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 硬闸分叉 | dry-run 已证明会放过 RSI/MA20 超限 | 先做入场拦截对齐 |
| 重复买同一只 | Agent 和 tick 各买一次 | 单日成交上限 + 持仓检查 |
| 计划被反复改 | P1b 写入后可能高频改止损 | 20h 冷却 + 2% 台阶 + rev_count |
| token 浪费 | 反复评估非防御标的 | context 里先按档位过滤候选 |
